# ⏰ Smart Attendance — V2.0 ULTIMATE

Aplikasi absensi web enterprise-grade dengan verifikasi multi-faktor, AI analytics, dan gamifikasi.

## ✨ Fitur V2.0 (LENGKAP)

### 🔐 Keamanan Tingkat Lanjut
- ✅ **QR Code Berputar** — Token regenerasi tiap 60 detik (anti-foto)
- ✅ **GPS Geofencing** — Verifikasi lokasi dengan akurasi tinggi
- ✅ **Wi-Fi Fingerprinting** — Deteksi jaringan kantor
- ✅ **Anti-Fake GPS** — Deteksi mock location & spoofing
- ✅ **Offline Mode** — Absen tetap tercatat tanpa sinyal (auto-sync)

### 🧠 Kecerdasan Buatan
- ✅ **AI Risk Scoring** — Skor risiko per karyawan (0-100)
- ✅ **Pattern Detection** — Deteksi pola keterlambatan
- ✅ **Burnout Prediction** — Prediksi risiko kelelahan
- ✅ **Anomaly Detection** — Identifikasi aktivitas mencurigakan
- ✅ **Trend Analysis** — Prediksi keterlambatan minggu depan

### 🎮 Gamifikasi
- ✅ **Point System** — Poin untuk kehadiran tepat waktu
- ✅ **Badge Collection** — Koleksi badge (Early Bird, Streak, dll)
- ✅ **Mood Check-in** — Karyawan isi mood setelah absen pulang
- ✅ **Leaderboard** — Ranking karyawan paling rajin

### 💬 Integrasi Telegram
- ✅ **Auto Reminder** — Notifikasi karyawan yang belum absen
- ✅ **Late Alert** — Notifikasi admin saat karyawan terlambat
- ✅ **Leave Approval** — Notifikasi approval/rejection cuti
- ✅ **Real-time Updates** — Update status langsung ke Telegram

### 📊 Dashboard Premium
- ✅ **Dark Glassmorphism** — UI admin modern & profesional
- ✅ **Light Pastel Theme** — UI karyawan friendly & mobile-like
- ✅ **Live Feed** — Data absensi real-time
- ✅ **Visual Analytics** — Chart & grafik interaktif
- ✅ **CSV Export** — Laporan bulanan siap pakai

### 🏖️ Manajemen Cuti
- ✅ **Multi-type Leave** — Cuti, Izin, Sakit
- ✅ **Approval Workflow** — Sistem persetujuan bertingkat
- ✅ **Attachment Support** — Upload dokumen pendukung
- ✅ **Status Tracker** — Pantau status pengajuan real-time

### 🕐 Manajemen Shift
- ✅ **Flexible Scheduling** — Multi-shift dengan toleransi
- ✅ **Auto-assignment** — Assign shift ke karyawan
- ✅ **Late Tolerance** — Toleransi keterlambatan per shift

### 📍 Manajemen Lokasi
- ✅ **Multi-location** — Support banyak kantor/cabang
- ✅ **QR Display Kiosk** — Layar QR untuk absen bersama
- ✅ **Token Rotation** — Ganti token QR kapan saja

## 🛠 Tech Stack

- **Backend:** PHP 7.4+ (Native, PDO)
- **Database:** MySQL / MariaDB
- **Frontend:** Vanilla JavaScript + Html5-QRCode
- **Styling:** Custom CSS (Dark & Light themes)
- **PWA:** Service Worker + Offline Support
- **Notifications:** Telegram Bot API
